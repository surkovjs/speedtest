# speedtest

Консольный скрипт на Node.js для замера скорости скачивания.

Скрипт принимает URL (лучше всего — тяжёлый файл, например большая картинка),
делает к нему **10 запросов последовательно**, каждый раз дожидаясь полного
получения тела ответа, и печатает время и размер каждого запроса, среднее время
запроса, общий объём данных и скорость скачивания.

## Требования

Node.js **18 или новее** (используется встроенный `fetch`). Зависимостей нет,
`npm install` не нужен.

## Запуск

```bash
node speedtest.js <url>
```

Пример:

```bash
node speedtest.js https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/x86_64/alpine-standard-3.20.3-x86_64.iso
```

Трафик за один запуск равен размеру файла × 10, поэтому для медленного или
лимитного интернета берите файл поменьше (например, на 10 МиБ).

## Единицы измерения

| Величина | Единица |
|---|---|
| Время | миллисекунды (ms) |
| Объём данных | байты, KiB, MiB, GiB (1 KiB = 1024 B), подбирается автоматически |
| Скорость | **MiB/s** (основная) и Mbit/s в скобках |

Mbit/s десятичные (1 Mbit = 1 000 000 бит) — в таких единицах скорость обычно
указывают провайдеры, так что результат удобно сверять с тарифом.

## Как считается скорость

```
среднее время запроса = сумма времён / 10
скорость              = суммарные байты / суммарное время запросов
```

Время запроса — от отправки до получения последнего байта тела ответа, то есть
включает установку соединения и ожидание первого байта. Поэтому на маленьких
файлах скорость будет заниженной — берите файл от нескольких МиБ.

## Поведение при ошибках

- Любая ошибка запроса (сеть, статус не 2xx, таймаут 60 с) останавливает скрипт
  с сообщением и кодом выхода 1: замер считается недействительным.
- Некорректный URL или отсутствие аргумента — код выхода 1.
- Редиректы выполняются автоматически.

Результат зависит от сервера и загруженности сети; если файл отдаётся из кеша
CDN, скорость может оказаться завышенной.
